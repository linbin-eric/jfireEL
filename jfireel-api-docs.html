项目概述

JfireEL 是一个轻量级、高性能的Java表达式语言（Expression Language）引擎。它支持丰富的表达式语法，包括算术运算、逻辑运算、方法调用、属性访问以及基本的控制流。通过将表达式字符串解析为可执行的Operand对象，JfireEL可以高效地在运行时动态计算代码逻辑。

核心API

JfireEL框架主要由以下几个核心类组成：

1. Expression (静态工具类)

这是一个静态工具类，是使用JfireEL的主要入口。它提供了静态方法来解析表达式字符串、注册全局函数和类。

关键方法:

1. 表达式解析 (Parsing)

  • public static Operand parse(String el):
    在默认的Matrix上下文中解析表达式字符串，返回可执行的Operand对象。
  • public static Operand parse(String el, String matrixName):
    在指定名称的Matrix上下文中解析表达式。如果该名称的Matrix不存在，将使用默认的Matrix。
  • public static Operand parse(String el, Matrix matrix):
    在给定的Matrix实例中解析表达式，提供更灵活的上下文管理。
  • public static Operand parse(String el, ELConfig config):
    使用自定义的ELConfig配置，在默认Matrix中解析表达式。
  • public static Operand parse(String el, String matrixName, ELConfig config):
    使用自定义配置，在指定名称的Matrix中解析表达式。
  • public static Operand parse(String el, Matrix matrix, ELConfig config):
    最完整的解析方法，允许同时指定Matrix实例和ELConfig配置。

2. 功能注册 (Registration)

  • public static void registerClass(String name, Class<?> clazz):
    在默认Matrix中注册一个类，之后可以在表达式中通过名称使用它。
  • public static void registerClass(String name, Class<?> clazz, String matrixName):
    将一个类注册到指定名称的Matrix中，实现作用域隔离。
  • public static void registerFunctionCall(String functionBody):
    在默认Matrix中注册一个或多个以EL语法写成的自定义函数。
  • public static void registerFunctionCall(String functionBody, String matrixName):
    将自定义函数注册到指定名称的Matrix中。
  • public static void registerReferenceCall(String name, Method method):
    将一个Java方法注册为可在EL中调用的引用函数（默认Matrix）。
  • public static void registerReferenceCall(String name, Method method, String matrixName):
    将引用函数注册到指定名称的Matrix中。
  • public static void scanForReferenceCall(Class<?> clazz):
    扫描一个类，自动将所有标注了@ReferenceCall注解的公共方法注册为EL函数。

3. 性能加速 (Acceleration)

  • public static void registerAcceleratorForPropertyRead(Field field, Function<Object, Object> accelerator):
    为特定字段的属性读取注册一个加速器（Function），以替代反射，提升性能（默认Matrix）。
  • public static void registerAcceleratorForPropertyRead(Field field, Function<Object, Object> accelerator, String matrixName):
    将属性读取加速器注册到指定名称的Matrix中。
  • public static void registerAcceleratorForMethodInvoke(Executable executable, MethodInvoker methodInvoker):
    为特定方法（或构造函数）的调用注册一个MethodInvoker加速器（默认Matrix）。
  • public static void registerAcceleratorForMethodInvoke(Executable executable, MethodInvoker methodInvoker, String matrixName):
    将方法调用加速器注册到指定名称的Matrix中。

4. 代码格式化 (Formatting)

  • public static String format(String content):
    对EL表达式代码进行美化格式化。它会自动处理换行和缩进，使代码更具可读性。

2. Operand

Operand 代表一个已编译的、可执行的表达式。它是 Expression.parse(...) 方法的返回结果。

关键方法:

  • public Object calculate(Map vars):
    在给定的Map变量环境中执行表达式，并返回计算结果。这个Map提供了表达式执行时所需的运行时变量。
  • public Object calculate():
    执行一个不含外部变量的表达式。

3. Matrix (分层上下文)

Matrix 是JfireEL中一个至关重要的概念。它并非一个简单的变量容器，而是一个**分层的上下文环境**，用于隔离和管理函数、类和变量的作用域。

通过将多个Matrix实例链接成一个父子关系的链条，可以构建出不同的作用域。当引擎在表达式中寻找一个函数或变量时，它会**从当前的Matrix开始查找，如果找不到，则会沿着父级链一直向上查找**，直到找到匹配项或到达最顶层的根Matrix。

这种设计使得在不同作用域中定义同名但不同实现的函数成为可能，有效地避免了命名冲突，是实现词法作用域的关键。

用法: 用户通常不需要直接创建或管理Matrix实例。相反，Matrix是在需要时，通过Expression的静态方法由JfireEL隐式创建和管理的。通过在以下方法中提供一个matrixName字符串，即可利用Matrix的上下文功能：

  • Expression.parse(String text, String matrixName)
  • Expression.registerFunctionCall(String functionBody, String matrixName)
  • Expression.registerClass(String name, Class clazz, String matrixName)

当你为这些方法提供一个名称时，JfireEL会查找或创建一个同名的Matrix，从而将操作限定在该上下文中。

用法示例

1. 基本运算

算术与逻辑运算

执行标准的数学和逻辑运算。

数字类型兼容性与自动提升

JfireEL在处理混合数字类型的运算时，遵循一套明确的自动类型提升规则，以确保精度和一致性。当不同类型的数字进行运算时，它们会被自动转换为范围更广的类型。规则优先级如下：

  1. BigDecimal (最高优先级): 如果参与运算的任何一方是 BigDecimal 类型，另一方也会被转换为 BigDecimal，计算结果为 BigDecimal。这保证了最高的计算精度。
  2. Double: 如果没有任何一方是 BigDecimal，但有一方是 Double 类型，另一方会被转换为 Double，计算结果为 Double。
  3. Float: 如果没有 BigDecimal 或 Double，但有一方是 Float 类型，另一方会被转换为 Float，计算结果为 Float。
  4. Long: 如果只有整数类型参与运算，且其中一方是 Long，另一方（如 Integer, Short, Byte）会被提升为 Long，计算结果为 Long。
  5. Integer (默认整数类型): 如果所有参与运算的数字都是整型且非Long（即 Integer, Short, Byte），它们将被视为 Integer 进行计算，结果为 Integer。

特殊情况 (+ 运算符):

加法运算符 (+) 有一个特殊行为：如果参与运算的任何一方是 String 类型，另一方也会被转换为字符串，整个表达式将执行字符串拼接操作。 

// 示例
Expression.parse("1 + 2L").calculate();       // Long + Integer -> Long (结果: 3L)
Expression.parse("1.5f + 2L").calculate();    // Float + Long -> Float (结果: 3.5f)
Expression.parse("1.5d + 2f").calculate();    // Double + Float -> Double (结果: 3.5d)
Expression.parse("'Hello ' + 123").calculate(); // String + Integer -> String (结果: "Hello 123")

// 解析并计算
Object result1 = Expression.parse("10 * (5 + 2)").calculate();
System.out.println(result1); // 输出: 70

// 逻辑比较
Object result2 = Expression.parse("(2+1!=2) == true && (100 > 99)").calculate();
System.out.println(result2); // 输出: true

三元运算符

支持 condition ? value_if_true : value_if_false 语法。

Object result = Expression.parse("2 > 1 ? 'Yes' : 'No'").calculate();
System.out.println(result); // 输出: Yes

2. 数据访问

访问数组、List和Map

使用 [] 语法访问集合中的元素。

// 准备数据
Map<String, Object> vars = new HashMap<>();
vars.put("myArray", new int[]{10, 20, 30});
vars.put("myList", Arrays.asList("A", "B", "C"));
vars.put("myMap", Collections.singletonMap("key", "value"));
vars.put("mapKey", "key");

// 访问数组
Object result1 = Expression.parse("myArray[1]").calculate(vars);
System.out.println(result1); // 输出: 20

// 访问List
Object result2 = Expression.parse("myList[2]").calculate(vars);
System.out.println(result2); // 输出: C

// 访问Map（使用字面量或变量作为键）
Object result3 = Expression.parse("myMap['key']").calculate(vars);
System.out.println(result3); // 输出: value

Object result4 = Expression.parse("myMap[mapKey]").calculate(vars);
System.out.println(result4); // 输出: value

3. 对象和类

方法调用和属性访问

// 准备一个自定义对象
public class User {
    public String name = "Gemini";
    public String getName() { return this.name; }
}
Map<String, Object> vars = new HashMap<>();
vars.put("user", new User());

// 访问属性
Object result1 = Expression.parse("user.name").calculate(vars);
System.out.println(result1); // 输出: Gemini

// 调用方法
Object result2 = Expression.parse("user.getName().length()").calculate(vars);
System.out.println(result2); // 输出: 6

静态成员访问

通过 registerClass 或 @(...) 语法访问静态成员。

// 方式一: 注册后使用
Expression.registerClass("StringUtil", String.class);
Object result1 = Expression.parse("StringUtil.valueOf(123)").calculate();
System.out.println(result1); // 输出: "123"

// 方式二: 使用完全限定类名
Object result2 = Expression.parse("@(java.lang.Math).max(10, 20)").calculate();
System.out.println(result2); // 输出: 20

创建实例和集合

// 注册类
Expression.registerClass("Person", Person.class); // 假设Person类已定义

// 创建 new 实例
Object person = Expression.parse("new Person(30)").calculate(); // 假设有 new Person(int age) 构造函数

// 创建数组
Object array = Expression.parse("['a', 'b', 'c']").calculate();

// 创建Set
Object set = Expression.parse("<<'a', 'b', 'a'>>").calculate();
System.out.println(set); // 输出: [a, b] (Set内容)

4. 流程控制

变量和if-else

String script = """
    if (score >= 60) {
        var level = 'Pass';
        return level;
    } else {
        var level = 'Fail';
        return level;
    }
    """;
Operand operand = Expression.parse(script);
Map<String, Object> vars = new HashMap<>();
vars.put("score", 75);
System.out.println(operand.calculate(vars)); // 输出: Pass

vars.put("score", 50);
System.out.println(operand.calculate(vars)); // 输出: Fail

For循环

String script = """
    var sum = 0;
    for (item in items) {
        sum = sum + item;
    }
    return sum;
    """;
Operand operand = Expression.parse(script);
Map<String, Object> vars = new HashMap<>();
vars.put("items", new int[]{1, 2, 3, 4, 5});
System.out.println(operand.calculate(vars)); // 输出: 15

5. 自定义函数

在EL中定义函数

使用 function 关键字在脚本中定义函数，支持重载和注释。

// 注册一个函数
String funcScript = """
# 这是一个加法函数
function my_add(int a, int b) {
    return a + b;
}
""";
Expression.registerFunctionCall(funcScript, "my_scope");

// 在相同的scope中调用它
Operand operand = Expression.parse("my_add(10, 20)", "my_scope");
System.out.println(operand.calculate()); // 输出: 30

注册Java方法作为函数

可以通过 registerReferenceCall 或 @ReferenceCall 注解将原生Java方法映射为EL函数。

// 假设有 public static int MyMath.add(int a, int b)
Method method = MyMath.class.getMethod("add", int.class, int.class);
Expression.registerReferenceCall("add_native", method);

Object result = Expression.parse("add_native(5, 3)").calculate();
System.out.println(result); // 输出: 8

通过注解自动注册Java方法

使用 @ReferenceCall 注解可以更方便地批量注册方法。只需在静态方法上添加该注解，然后调用 scanForReferenceCall 即可。

// 1. 定义一个包含注解方法的工具类
public class MyFunctions {
    @ReferenceCall("add") // 在EL中暴露为 "add"
    public static int sum(int a, int b) {
        return a + b;
    }

    @ReferenceCall // 如果不指定名称，则使用方法名 "subtract"
    public static int subtract(int a, int b) {
        return a - b;
    }
    
    @ReferenceCall(matrixName = "special_scope") // 可以在特定scope中注册
    public static int multiply(int a, int b) {
        return a * b;
    }
}

// 2. 扫描该类以自动注册所有带注解的方法
Expression.scanForReferenceCall(MyFunctions.class);

// 3. 调用在默认scope中注册的函数
Object result1 = Expression.parse("add(10, 5)").calculate();
System.out.println(result1); // 输出: 15

Object result2 = Expression.parse("subtract(10, 5)").calculate();
System.out.println(result2); // 输出: 5

// 4. 调用在特定scope中注册的函数
Object result3 = Expression.parse("multiply(10, 5)", "special_scope").calculate();
System.out.println(result3); // 输出: 30

6. 模板引擎

JfireEL也提供了一个简单的模板引擎，用于字符串渲染。

import com.jfirer.jfireel.template.Template;

Map<String, Object> vars = new HashMap<>();
vars.put("name", "world");
vars.put("items", Arrays.asList("A", "B"));

// 简单变量插值
String result1 = Template.parse("Hello, ${name}!").render(vars);
System.out.println(result1); // 输出: Hello, world!

// 嵌入控制流脚本
String tpl = "Items:<% for(item in items) { %> ${item}<% } %>";
String result2 = Template.parse(tpl).render(vars);
System.out.println(result2); // 输出: Items: A B
