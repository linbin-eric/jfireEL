# JfireEL 框架入门手册

## 简介

**JfireEL** 是一个轻量级、高性能的Java表达式语言（Expression Language）引擎。它支持完整的表达式语法、控制流、函数定义和模板渲染功能，可以用于规则引擎、配置解析、动态计算、模板渲染等多种场景。

**核心特性：**
- 支持丰富的表达式语法（算术、逻辑、比较运算）
- 支持对象属性访问和方法调用
- 支持变量声明、条件语句、循环控制
- 支持自定义函数注册和调用
- 内置模板引擎，支持动态内容渲染
- 高性能：支持编译模式优化
- 灵活的作用域管理

---

## 快速开始

### Maven 依赖

```xml
<dependency>
    <groupId>com.jfirer</groupId>
    <artifactId>jfireEL</artifactId>
    <version>1.1-SNAPSHOT</version>
</dependency>
```

### 第一个示例

```java
import com.jfirer.jfireel.expression.Expression;
import com.jfirer.jfireel.expression.Operand;

public class HelloJfireEL {
    public static void main(String[] args) {
        // 解析并执行简单表达式
        Operand op = Expression.parse("10 * (5 + 2)");
        Object result = op.calculate();
        System.out.println(result); // 输出: 70
    }
}
```

## 核心API使用指南

### 一、Expression - 表达式解析入口

`Expression` 是 JfireEL 的主入口类，提供所有表达式解析和配置方法。

#### 1. `Expression.parse()` - 解析表达式

**用途：** 将字符串形式的表达式解析为可执行的 `Operand` 对象。

**方法签名：**
```java
static Operand parse(String el)
static Operand parse(String el, String matrixName)
static Operand parse(String el, Matrix matrix)
static Operand parse(String el, ELConfig config)
static Operand parse(String el, String matrixName, ELConfig config)
static Operand parse(String el, Matrix matrix, ELConfig config)
```

**参数说明：**
- `el`: 表达式字符串
- `matrixName`: 作用域名称（可选）
- `matrix`: 作用域对象（可选）
- `config`: 性能配置（可选）

**场景用例1：基本数学计算**

```java
// 场景：在配置文件中定义折扣规则
// 需求：根据价格和折扣率计算最终价格
Operand op = Expression.parse("price * discount");

Map<String, Object> vars = new HashMap<>();
vars.put("price", 100.0);
vars.put("discount", 0.85);

Object finalPrice = op.calculate(vars);
System.out.println("最终价格: " + finalPrice); // 85.0
```

```java
// 需求：计算订单总金额，统计大额订单数量，找出最高金额订单
public class Order {
    private String orderId;
    private double amount;

    public Order(String orderId, double amount) {
        this.orderId = orderId;
        this.amount = amount;
    }

    public String getOrderId() { return orderId; }
    public double getAmount() { return amount; }
}

// 统计脚本
String script = """
    var totalAmount = 0;
    var largeOrderCount = 0;
    var maxAmount = 0;
    var maxOrderId = '';

    # 遍历所有订单
    for (order in orders) {
        # 累加总金额
        totalAmount = totalAmount + order.getAmount();

        # 统计大额订单（金额>=1000）
        if (order.getAmount() >= 1000) {
            largeOrderCount = largeOrderCount + 1;
        }

        # 找出最高金额订单
        if (order.getAmount() > maxAmount) {
            maxAmount = order.getAmount();
            maxOrderId = order.getOrderId();
        }
    }

    # 返回统计结果（使用数组）
    return [totalAmount, largeOrderCount, maxAmount, maxOrderId];
""";

Operand op = Expression.parse(script);

// 准备订单数据
Order[] orders = {
    new Order("ORD001", 500.0),
    new Order("ORD002", 1500.0),
    new Order("ORD003", 800.0),
    new Order("ORD004", 2000.0),
    new Order("ORD005", 300.0)
};

Map<String, Object> context = new HashMap<>();
context.put("orders", orders);

Object[] result = (Object[]) op.calculate(context);
System.out.println("订单总金额: " + result[0]);      // 5100.0
System.out.println("大额订单数: " + result[1]);      // 2
System.out.println("最高金额: " + result[2]);        // 2000.0
```

#### 2. `Expression.registerClass()` - 注册类

**用途：** 将Java类注册到表达式引擎中，使表达式可以通过简化名称创建对象或调用静态方法。

**方法签名：**
```java
static void registerClass(String name, Class<?> clazz)
static void registerClass(String name, Class<?> clazz, String matrixName)
```

**参数说明：**
- `name`: 在表达式中使用的简化名称
- `clazz`: 要注册的Java类
- `matrixName`: 作用域名称（可选）

**场景用例1：在表达式中使用自定义工具类**

```java
// 场景：在表达式中使用日期工具类
public class DateUtils {
    public static String formatDate(Date date, String pattern) {
        SimpleDateFormat sdf = new SimpleDateFormat(pattern);
        return sdf.format(date);
    }

    public static Date addDays(Date date, int days) {
        Calendar cal = Calendar.getInstance();
        cal.setTime(date);
        cal.add(Calendar.DAY_OF_MONTH, days);
        return cal.getTime();
    }
}

// 注册工具类
Expression.registerClass("DateUtils", DateUtils.class);

// 使用工具类
String expr = "DateUtils.formatDate(currentDate, 'yyyy-MM-dd')";
Map<String, Object> vars = new HashMap<>();
vars.put("currentDate", new Date());

Object result = Expression.parse(expr).calculate(vars);
System.out.println("格式化日期: " + result);
```

**场景用例2：创建对象实例**

```java
// 场景：在配置规则中动态创建对象
// 需求：根据条件创建不同的消息对象
public class Message {
    private String title;
    private String content;

    public Message(String title, String content) {
        this.title = title;
        this.content = content;
    }

    public String getTitle() { return title; }
    public String getContent() { return content; }
}

// 注册Message类
Expression.registerClass("Message", Message.class);

// 动态创建对象
String expr = "new Message('系统通知', '您有新的消息')";
Operand op = Expression.parse(expr);
Message msg = (Message) op.calculate();

System.out.println(msg.getTitle());    // 系统通知
System.out.println(msg.getContent());  // 您有新的消息
```

#### 3. `Expression.registerFunctionCall()` - 注册自定义函数

**用途：** 使用EL语法定义自定义函数，可以在表达式中像内置函数一样调用。

**方法签名：**
```java
static void registerFunctionCall(String functionBody)
static void registerFunctionCall(String functionBody, String matrixName)
```

**参数说明：**
- `functionBody`: 函数定义代码（使用EL语法编写）
- `matrixName`: 作用域名称（可选）

**场景用例1：定义数学计算函数**

```java
// 场景：价格计算系统
// 需求：定义税费计算函数和折扣计算函数
Expression.registerFunctionCall("""
    function calculateTax(double price, double taxRate) {
        return price * taxRate;
    }
""");

Expression.registerFunctionCall("""
    function applyDiscount(double price, double discount, double minPrice) {
        var finalPrice = price * discount;
        if (finalPrice < minPrice) {
            return minPrice;
        }
        return finalPrice;
    }
""");

// 使用函数计算商品最终价格
String expr = """
    var basePrice = 1000.0;
    var tax = calculateTax(basePrice, 0.08);
    var discountedPrice = applyDiscount(basePrice, 0.9, 500.0);
    return discountedPrice + tax;
""";

Object finalPrice = Expression.parse(expr).calculate();
System.out.println("最终价格: " + finalPrice); // 980.0
```

**场景用例2：定义业务规则函数**

```java
// 场景：风控系统
// 需求：定义风险评分计算函数
Expression.registerFunctionCall("""
    function calculateRiskScore(int creditScore, double debtRatio, int latePayments) {
        var score = 100;

        if (creditScore < 600) {

            score = score - 10;

        # 逾期次数影响
        score = score - (latePayments * 5);

    }
""");

// 评估用户风险

userInfo.put("debtRatio", 0.4);
userInfo.put("latePayments", 2);
```

#### 4. `Expression.registerReferenceCall()` - 注册Java方法引用

**用途：** 将已有的Java方法注册为EL函数，可以直接在表达式中调用。

**方法签名：**
```java
static void registerReferenceCall(String name, Method method)
static void registerReferenceCall(String name, Method method, String matrixName)
```

**参数说明：**
- `name`: 在表达式中的函数名称
- `method`: 要注册的Java方法对象（**必须是 public static 方法**）
- `matrixName`: 作用域名称（可选）

**重要限制：**
- 注册的方法必须是 **public static** 修饰的静态方法
- 非静态方法无法注册

**场景用例1：注册工具类方法**

```java
// 场景：字符串处理系统
// 需求：在表达式中使用字符串处理方法
public class StringUtils {
    public static String capitalize(String str) {
        if (str == null || str.isEmpty()) return str;
        return str.substring(0, 1).toUpperCase() + str.substring(1);
    }

    public static boolean isNumeric(String str) {
        return str != null && str.matches("\\d+");
    }

    public static String mask(String str, int visibleChars) {
        if (str == null || str.length() <= visibleChars) return str;
        String visible = str.substring(0, visibleChars);
        return visible + "*".repeat(str.length() - visibleChars);
    }
}

// 注册方法
Method capitalizeMethod = StringUtils.class.getMethod("capitalize", String.class);
Expression.registerReferenceCall("capitalize", capitalizeMethod);

Method isNumericMethod = StringUtils.class.getMethod("isNumeric", String.class);
Expression.registerReferenceCall("isNumeric", isNumericMethod);

Method maskMethod = StringUtils.class.getMethod("mask", String.class, int.class);
Expression.registerReferenceCall("mask", maskMethod);

// 使用注册的方法
Map<String, Object> vars = new HashMap<>();
vars.put("name", "john doe");
vars.put("phone", "13812345678");

String expr1 = "capitalize(name)";
System.out.println(Expression.parse(expr1).calculate(vars)); // John doe

String expr2 = "mask(phone, 3)";
System.out.println(Expression.parse(expr2).calculate(vars)); // 138********
```

**场景用例2：注册业务逻辑方法**

```java
// 场景：订单处理系统
// 需求：在规则引擎中使用订单验证逻辑
public class OrderValidator {
    public static boolean validateOrder(double amount, int quantity) {
        return amount > 0 && quantity > 0 && quantity <= 100;
    }

    public static double calculateShippingFee(double amount, String region) {
        if (amount >= 200) return 0.0;
        return "remote".equals(region) ? 20.0 : 10.0;
    }
}

// 注册方法
Method validateMethod = OrderValidator.class.getMethod(
    "validateOrder", double.class, int.class);
Expression.registerReferenceCall("validateOrder", validateMethod);

Method shippingMethod = OrderValidator.class.getMethod(
    "calculateShippingFee", double.class, String.class);
Expression.registerReferenceCall("calculateShipping", shippingMethod);

// 使用在订单处理流程中
String orderRule = """
    if (validateOrder(orderAmount, orderQuantity)) {
        var shipping = calculateShipping(orderAmount, region);
        return orderAmount + shipping;
    } else {
        return -1;
    }
""";

Map<String, Object> order = new HashMap<>();
order.put("orderAmount", 150.0);
order.put("orderQuantity", 3);
order.put("region", "normal");

double totalAmount = (double) Expression.parse(orderRule).calculate(order);
System.out.println("订单总额: " + totalAmount); // 160.0
```

#### 5. `Expression.scanForReferenceCall()` - 扫描注解方法

**用途：** 自动扫描类中所有带 `@ReferenceCall` 注解的方法，并批量注册为EL函数。

**方法签名：**
```java
static void scanForReferenceCall(Class<?> clazz)
```

**参数说明：**
- `clazz`: 要扫描的类

**重要说明：**
- 只有 **public static** 修饰的方法才能被成功注册
- 非静态方法或非公开方法会被忽略

**场景用例1：批量注册工具方法**

```java
// 场景：数学计算工具
// 需求：提供一组数学函数供表达式使用
public class MathFunctions {

    @ReferenceCall("add")
    public static int add(int a, int b) {
        return a + b;
    }

    @ReferenceCall("multiply")
    public static int multiply(int a, int b) {
        return a * b;
    }

    @ReferenceCall("power")
    public static double power(double base, double exponent) {
        return Math.pow(base, exponent);
    }

    @ReferenceCall("max")
    public static int max(int a, int b, int c) {
        return Math.max(Math.max(a, b), c);
    }
}

// 批量注册所有方法
Expression.scanForReferenceCall(MathFunctions.class);

// 使用注册的函数
String expr = "add(10, multiply(3, 4)) + power(2, 3)";
Object result = Expression.parse(expr).calculate();
System.out.println("计算结果: " + result); // 30.0
```

**场景用例2：注册到指定作用域**

```java
// 场景：多租户系统
```

### 二、Operand - 可执行表达式

`Operand` 是表达式解析后得到的可执行对象。

#### 1. `calculate()` - 执行表达式

**用途：** 在给定的上下文变量中执行表达式，返回计算结果。

**方法签名：**
```java
Object calculate(Map<String, Object> contextParam)
Object calculate()  // 无参版本
```

**参数说明：**
- `contextParam`: 上下文变量Map，包含表达式中使用的变量

**场景用例1：动态规则执行**

```java
// 场景：促销活动规则引擎
// 需求：根据不同的促销规则计算优惠金额
public class PromotionEngine {
    private Map<String, Operand> rules = new HashMap<>();

    public void loadRule(String ruleId, String ruleExpression) {
        rules.put(ruleId, Expression.parse(ruleExpression));
    }

    public double applyRule(String ruleId, Map<String, Object> orderData) {
        Operand rule = rules.get(ruleId);
        if (rule != null) {
            return (double) rule.calculate(orderData);
        }
        return 0.0;
    }
}

// 使用示例
PromotionEngine engine = new PromotionEngine();

// 加载不同的促销规则
engine.loadRule("newUser", "orderAmount >= 100 ? 20.0 : 0.0");
engine.loadRule("vip", "orderAmount * 0.15");
engine.loadRule("festival", "orderAmount >= 200 ? 50.0 : orderAmount >= 100 ? 20.0 : 0.0");

// 应用规则
Map<String, Object> order = new HashMap<>();
order.put("orderAmount", 250.0);

double discount1 = engine.applyRule("newUser", order);   // 20.0
double discount2 = engine.applyRule("vip", order);       // 37.5
double discount3 = engine.applyRule("festival", order);  // 50.0
```

**场景用例2：表达式复用**

```java
// 场景：批量数据处理
// 需求：用同一个规则处理多条数据
String formula = "score * weight + bonus";

);

for (Map<String, Object> student : students) {

}
// 输出:
// 最终得分: 64.5
// 最终得分: 74.4
// 最终得分: 54.6
```

### 三、Matrix - 作用域管理

`Matrix` 用于管理变量、函数和类的作用域，支持作用域隔离和继承。

**用途：** 在多租户、多环境或需要命名空间隔离的场景中使用。

**场景用例1：多租户隔离**

```java
// 场景：SaaS平台
// 需求：不同租户使用不同的业务规则
import com.jfirer.jfireel.expression.Matrix;

// 为租户A创建独立作用域
Expression.registerFunctionCall("""
    function calculateFee(double amount) {
        return amount * 0.02;  # 2%手续费
    }
""", "tenantA");

// 为租户B创建独立作用域
Expression.registerFunctionCall("""
    function calculateFee(double amount) {
        return amount * 0.03;  # 3%手续费
    }
""", "tenantB");

// 租户A的计费
```

### 五、ELConfig - 性能配置

`ELConfig` 用于开启编译优化，提升表达式执行性能。

**用途：** 在性能敏感场景中，通过启用编译模式减少反射开销。

```java
    .setMathUseCompile(true)              // 数学运算编译优化
    .setMethodInvokeUseCompile(true)      // 方法调用编译优化
    .setPropertyReadUseCompile(true)      // 属性读取编译优化
    .setPlusUseCompile(true)              // 加法优化
    .setMultiplyUseCompile(true)          // 乘法优化
    .setGtUseCompile(true)                // 比较运算优化
    .setEqUseCompile(true);               // 等于运算优化

// 使用优化配置解析表达式
String expr = "data.getValue() * 1.08 + data.getBonus()";
Operand op = Expression.parse(expr, highPerformanceConfig);

// 高频执行
for (int i = 0; i < 1000000; i++) {
    Map<String, Object> context = new HashMap<>();
    context.put("data", new DataObject());
    double result = (double) op.calculate(context);
```

### 六、@ReferenceCall - 方法注解

**用途：** 标记方法，使其能被自动扫描并注册为EL函数。

**注解属性：**
- `value`: 函数名称（可选，默认使用方法名）
- `matrixName`: 作用域名称（可选，默认为默认作用域）

**重要限制：**
- 被注解的方法必须是 **public static** 修饰的静态方法
- 非静态方法无法被注册

**场景用例：构建函数库**

```java
// 场景：通用函数库
// 需求：提供一组常用函数供表达式使用
public class CommonFunctions {

    // 字符串函数
    @ReferenceCall
    public static int length(String str) {
        return str == null ? 0 : str.length();
    }

    @ReferenceCall
    public static String substring(String str, int start, int end) {
        return str.substring(start, end);
    }

    @ReferenceCall
    public static boolean isEmpty(String str) {
        return str == null || str.isEmpty();
    }

    // 数学函数
    @ReferenceCall
    public static double round(double value, int precision) {
        double scale = Math.pow(10, precision);
        return Math.round(value * scale) / scale;
    }

    @ReferenceCall
    public static int abs(int value) {
        return Math.abs(value);
    }

    // 日期函数
    @ReferenceCall
    public static boolean isWeekend(Date date) {
        Calendar cal = Calendar.getInstance();
        cal.setTime(date);
        int dayOfWeek = cal.get(Calendar.DAY_OF_WEEK);
        return dayOfWeek == Calendar.SATURDAY || dayOfWeek == Calendar.SUNDAY;
    }
}

// 注册所有函数
Expression.scanForReferenceCall(CommonFunctions.class);

// 使用函数
String expr1 = "length('Hello World')";  // 11
String expr2 = "round(3.14159, 2)";       // 3.14
String expr3 = "isEmpty(name)";           // true/false
```

## 性能优化建议

1. **表达式复用**：解析后的 `Operand` 对象可以多次执行，避免重复解析
2. **启用编译模式**：对于高频执行的表达式，使用 `ELConfig` 开启编译优化
3. **合理使用作用域**：通过 `Matrix` 隔离不同上下文，避免命名冲突
4. **注册加速器**：对性能关键的属性读取和方法调用注册加速器
5. **避免复杂嵌套**：过深的嵌套会影响性能，适当拆分表达式

## 常见问题

### Q1: 如何调试表达式？
**A:** 可以使用 `Expression.format()` 格式化表达式代码，或在表达式中输出中间变量值。

### Q2: 表达式中可以使用Java标准库吗？
**A:** 需要先通过 `Expression.registerClass()` 注册类，然后才能在表达式中使用。

### Q3: 如何处理表达式执行异常？
**A:** 将 `calculate()` 调用放在 try-catch 块中捕获异常。

```java
try {
    Object result = op.calculate(vars);
} catch (Exception e) {
    // 处理异常
    e.printStackTrace();
}
```

### Q4: 表达式中的变量类型如何确定？
**A:** JfireEL 支持自动类型推断和类型转换，大多数情况下不需要显式指定类型。

### Q5: 如何实现表达式的持久化？
**A:** 将表达式字符串保存到数据库或配置文件，使用时通过 `Expression.parse()` 加载。
